# Análise de Dados - Base mtcars (R)

Projeto de análise de dados desenvolvido em R utilizando a base de dados `mtcars`, disponível nativamente no R.

## 📊 Sobre o Projeto

Este projeto tem como objetivo explorar a relação entre o número de cilindros dos veículos e duas variáveis de desempenho: consumo de combustível e potência do motor.

## 🔍 Análises Realizadas

- **Consumo médio por cilindro**: cálculo da média de consumo (mpg) agrupada pelo número de cilindros.
- **Potência média por cilindro**: cálculo da média de potência (hp) agrupada pelo número de cilindros.
- **Gráfico de dispersão**: visualização da relação entre consumo e potência, destacando o agrupamento por cilindros.

## 🛠️ Tecnologias Utilizadas

- R
- Base de dados `mtcars`

## 📈 Resultados

O resumo estatístico e o gráfico gerado permitem visualizar como o número de cilindros impacta diretamente tanto o consumo quanto a potência dos veículos, evidenciando a relação inversa entre essas variáveis.

## ▶️ Como Executar

1. Clone este repositório
2. Abra o script no RStudio (ou ambiente de sua preferência)
3. Execute o script para gerar os resumos estatísticos e o gráfico
